# Tests

The guard's tests: planted emails, secrets and session data fail it, clean files pass. `check-version.test.sh` makes branches in a scratch repo: a shipped change with no new version fails, and docs, tests or a bump pass. `commands.test.sh` holds clarify, regroup and sitrep to their shape, and regroup to tools that only read. `structured.test.sh` keeps emoji out of the output style. `closed.test.sh` holds the plugin to what ships inside it: each `ortonom:<name>` it names ships, no agent pins a model, no home-directory path but Claude Code's own, and, on a machine with skills and agents of its own, none of their names outside `hooks/companions.ts`, which checks for each at session start, and the place table's entries in `hooks/places.ts`, which name the folders other tools keep plans in. `statusline.test.sh` feeds the status line and agent panel the status-line input Claude Code sends and checks every row; `statusline-wiring.test.sh` checks that installing the plugin brings them: the session-start copy, the agent panel setting and `/ortonom:statusline`. `state-version.test.sh` holds every key that carries the focus state's version to one number. `contracts.test.sh` holds the names no one module owns: every state file the hooks or the status line name is one the prune deletes, and every skill the sidebar, the companions or the skin name by hand is one the plugin ships, and no text a hook logs starts with the plugin's name, which Claude Code puts in front of each line. `readme.test.sh` holds the README's health score and levels to the hooks' numbers, and has it name every skill, agent and command the plugin ships.
