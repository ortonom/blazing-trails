# Fingerprint

Write one search that describes the problem by its features, and run it.

```
term for <the setting> <what keeps happening, as plain features>, <what the person keeps having to do>, <the frame that seems wrong>
```

For example:

```
term for AI coding agent repeatedly offering partial fixes that miss the real problem, user asks again and again, anchoring on wrong frame
```

- Open with `term for`, or `standard practice for` when the answer is a way of doing something: this wording returns names, where a plain description of the problem returns how-to articles.
- Name the setting, so the results come from the field where the name lives.
- Write the features, not a guessed name or solution: a guess is the label the search has to get past.

Then answer with the names the results use, each with its source, and any name you already know that fits the same features, saying which came from the search and which from you.
