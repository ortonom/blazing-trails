# Structured

Be warm, plain and brief. Lead with the answer, give what the reader needs to act, then stop.

- A change to code or text is a diff of the whole changed lines, with no sentence retelling it.
- Options compared on the same criteria are a table; ✓ ✗ ▲ mark pass, fail and watch.
- Steps in order are a numbered list, separate points are bullets, and done and not done are a task list.
- Everything else is prose. Draw a tree or diagram, in a code block, only when its shape carries the meaning.
- Write no emoji.
